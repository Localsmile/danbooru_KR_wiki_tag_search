# danbooru_KR_wiki_tag_search

Danbooru 태그를 한국어 설명으로 검색하고 프롬프트 작성에 활용할 수 있는 정적 웹 도구입니다.

[웹에서 사용하기](https://localsmile.github.io/danbooru_KR_wiki_tag_search/)

## 기능

- 한국어 설명과 키워드로 Danbooru 태그 검색
- 태그 바로 복사 및 여러 태그 모아 복사
- 밑줄, 공백, 괄호 이스케이프, 구분자 형식 설정
- 태그별 대표 이미지 미리보기
- 프롬프트 형식 변환
- 아티스트 작품 검색
- 캐릭터 코어태그 검색

## 미리보기

- Danbooru 위키에 등록된 대표 예시를 우선 표시합니다.
- 대표 예시가 없으면 해당 태그의 고득점 게시물을 표시합니다.
- 2026.08.20: KT 인터넷 등 일부 환경의 태그 검색 미리보기 이미지 표시 문제 해결

## 데이터

- 태그 검색 데이터 기준일: 2026.03.23
- 게시물 수 100 이상인 태그의 한국어 설명을 제공합니다.
